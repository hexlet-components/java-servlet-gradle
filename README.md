# java-servlet-gradle

[![github action status](https://github.com/hexlet-components/java-servlet-gradle/workflows/Java%20CI/badge.svg)](https://github.com/hexlet-components/java-servlet-gradle/actions)

## Requirements

- JDK 27
- Make

## Setup

```bash
make setup
```

## Run server

```bash
make dev
# Open http://localhost:8080
```
